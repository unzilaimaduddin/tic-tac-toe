# Tic-Tac-Toe ❌⭕

A simple 2-player Tic-Tac-Toe game that runs in the browser.

## Features
- Two players take turns
- Automatically detects the winning line
- Option to restart the game

## Technologies
- HTML
- CSS
- JavaScript

## How to Run
Open the `index.html` file in your browser and start playing.
