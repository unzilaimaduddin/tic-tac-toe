# Tic-Tac-Toe ❌⭕

Ek simple 2-player Tic-Tac-Toe game jo browser mein khelta hai.

## Features
- 2 players baari baari khelte hain
- Jeetne wali line automatically detect hoti hai
- Game dobara shuru karne ka option

## Technologies
- HTML
- CSS
- JavaScript

## Kaise chalayein
`index.html` file browser mein kholo aur khelna shuru karo.
